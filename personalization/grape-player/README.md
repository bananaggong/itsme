# Grapes 음악 카드

`bananaggong/grapes-web`의 `6cf309d2353bef5a29f6c3ab011336539a97eb64`
커밋에서 `HeroCanvas.tsx`, Fibonacci 구면 배치, `SONGS` 17곡과 해당 MP3를 가져왔다.
기존 포트폴리오 운영 기준은 `ef43d54d4910fd9e794683afcd9148dbc9714089`이다.

원본 Three.js/GSAP 장면의 구면 배치, 재질·조명, 등장·회전, 포인터 조명,
곡명 뒤집기, 선택 시 앞으로 나오는 효과, 오디오 주파수에 따른 빛·크기·파형을
`scene.ts`에 유지했다. React/Next 런타임 없이 독립 ES 모듈로 실행한다.
원본의 전체 랜딩 페이지 대신 음악 카드만 표시한다.

`tools/grape-player.mjs`가 개인화 단계에서 Spotify 섹션과 모듈을 교체한다.
`tile--spotify` 식별자는 저장된 카드 순서·2×2 레이아웃·확대 전환 호환을 위해
유지하며, 화면과 편집 모드의 접근성 이름은 Grapes다. Freeform 보드를 확대해
카드가 한 줄 높이가 되면 포도알과 컨트롤을 가로로 배치한다. 사이트 검색도
기존 Spotify 링크 대신 Grapes 카드로 연결한다.
캡처 원본과 기준 태그는 변경하지 않는다.

## 빌드

```sh
npm ci --prefix personalization/grape-player --ignore-scripts
npm run build:grapes
npm run build
```

생성된 `public/personal/grapes/*.js`와 라이선스 고지는 소스와 함께 커밋한다.
Vercel 정적 빌드는 이 산출물을 사용하므로 운영 서버에 Three.js·GSAP·React를
설치하거나 외부 CDN을 호출할 필요가 없다. 장면 모듈은 카드가 가까워질 때
불러오며 음원은 선택한 곡만 가져온다. CSS와 진입 모듈에는 내용 해시가 붙는다.

## 동작 및 제약

- 저장소의 MP3 17개는 각각 약 12초 샘플이다. 전체 곡이나 스트리밍 연동이 아니다.
  사용자가 요청한 원본 파일을 같은 바이트로 제공한다.
- 포도알을 다시 누르면 일시정지하고 다시 누르면 이어 재생한다. 곡 선택은
  포도알 또는 이전·다음 버튼으로 한다. 상단 보조 문구·곡 선택 드롭다운·화면의
  일반 상태 문구는 제거하고 재생 상태는 스크린 리더에 알린다.
  기존 포도알 배치·색상·제목·재생 버튼·보라색 탐색 바를 유지한다.
  키보드 재생과 탐색 바를 지원하며 동시 재생은 한 곡으로 제한한다.
- 원본 Web Audio 버퍼 전체 선로딩·합성 대체음·곡 전환 크로스페이드 대신
  하나의 HTML Audio와 Web Audio 분석기를 사용한다. 작은 카드에서의 메모리
  사용량을 줄이고 일시정지·탐색을 지원한다. 파일 실패 시 실제 오류를 알리고
  재시도하며, 원곡 대신 합성음을 들려주지 않는다. 음량은 원본과 같은 35%다.
- 브라우저 정책에 따라 첫 재생은 클릭·터치·키보드 조작이 필요하다.
  WebGL이 없거나 컨텍스트를 잃으면 정적 포도알과 이전·다음·재생 버튼으로 계속 재생한다.
  JavaScript가 없으면 기본 오디오 컨트롤과 전체 음원 링크를 제공한다.
- 카드 밖·숨겨진 탭에서는 3D 렌더링을 쉬고 페이지를 떠나면 자원을 해제한다.
  동작 줄이기 설정에서는 연속 회전·호흡·음악 반응을 줄인다.
- 이식 시 카드 비율에 맞춰 카메라 거리를 조절했다. 곡 제목과 컨트롤은
  HTML로도 제공해 캔버스의 작은 글자에 의존하지 않는다.
- 실제 iPhone/Safari 기기는 이 작업 환경에서 직접 검증할 수 없다.
  브라우저 연결 도구가 제공되지 않아 로컬 Chromium/Playwright로 터치·작은 화면을 검증한다.
