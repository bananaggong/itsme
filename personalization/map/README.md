# 마장동 산책 지도

기준 주소는 서울 성동구 마장동 797-80(마조로15나길 7-1)이다.
좌표와 출처는 `config.json`에 기록했다. 주소 검색의 좌표는 건물·필지의
대표점이며 출입구나 보행 가능성을 보장하지 않는다.

## 로컬 적용 완료

2026-10-18 로컬 환경에서 `config.json`의 `dataUrl`로 OpenStreetMap 데이터를
받아 밝은/어두운 지도와 경로를 생성했다. 약 1,813.4m의 공개 도로 순환 경로는
마장동 797-80 주변 → 마장역 4번 출구 주변 → 왕십리역 6번 출구 주변 →
출발점으로 이어지며 같은 도로 구간을 되짚지 않는다.
첫 도로 노드는 주소 대표 좌표에서 약 1.3m 떨어져 있다. 경로는 마장역 출구에서
약 32m, 왕십리역 출구에서 약 8m 떨어진 공개 도로를 지난다. 역 안으로 진입하지
않고 두 역 주변을 순회하는 연출이다. 생성 지도와 경로, 집 아이콘이
모두 있을 때 응답과 정적 빌드에 적용되며 `/#majang-walk`로 바로 볼 수 있다.

원본 데이터는 Git에서 제외한 `.cache/map/majang.osm.json`에 보관한다.
재생성할 때는 저장한 파일을 사용한다. 새 데이터를 받으면 같은 명령으로
지도와 경로, 원본 SHA-256 및 노드 목록을 함께 갱신한다:

```sh
python tools/build-majang-map.py .cache/map/majang.osm.json
npm run build
```

`tools/build-majang-map.py`는 실제 노드로 연결된 공개 보행 도로에서 주소와
설정한 역 주변을 잇는 닫힌 순환 경로를 찾는다. 경유지가 없으면 출발점 근처의
짧은 골목 루프를 생성한다. 차량 전용 도로·사유지·보행 금지 구간을
제외하고, 도로를 가로지르는 임의 직선이나 동일 구간의 불필요한 왕복을 만들지
않는다. 적합한 루프를 찾지 못하면 오류로 멈춘다. 모서리는 교차점의 중심에서
1.5m 이내로 완만하게 이어 붙인다. 결과에는 출처 노드와 원본 데이터 해시가
남는다. 지도 데이터는 ODbL을 따르며 기존 OpenStreetMap 출처 표기를 유지한다.
`provenance.json`에는 다운로드 URL과 원본 파일의 수정 시각도 기록한다.

생성 결과는 `public/personal/map/`의 밝은/어두운 SVG와 `route.json`이다.
기존 사진 핀·하단 카드·테마·화면 밖 일시정지를 유지하며 한 바퀴는 45초다.
지도 범위는 약 1.2km로 넓혔으며 실제 OSM 역 좌표에 두 역 이름을 표시한다.
집 위치는 `config.json`의 주소 좌표를 사용하며, 지도 크기가 바뀌어도 같은
위치에 고정되는 파란 원형 표식으로 표시한다. 아이콘은 구글 공식 Material
Symbols의 `home` 원본을 사용하며, 출처·SHA-256·Apache 2.0 라이선스는
`vendor/`에 보존한다. 공개 산출물에는 흰색으로 칠한 아이콘과 라이선스를 포함한다.
하단 카드 제목은 `출근길`, 보조 문구는 `마조로 15나길 7-1`로 고정한다.
지도 확대·드래그·GPS 추적은 이 변경 범위에 포함하지 않는다.

실제 현장 보행 가능성이나 최신 공사·통행 제한은 OSM만으로 보장할 수 없다.
산책을 표현하는 애니메이션이며 실시간 위치 또는 길 안내가 아니다.
