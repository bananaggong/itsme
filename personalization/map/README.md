# 마장동 산책 지도

기준 주소는 서울 성동구 마장동 797-80(마조로15나길 7-1)이다.
좌표와 출처는 `config.json`에 기록했다. 주소 검색의 좌표는 건물·필지의
대표점이며 출입구나 보행 가능성을 보장하지 않는다.

## 데이터가 필요한 상태

현재 관리형 환경의 네트워크 허용목록에는 OpenStreetMap API 서버가 없다.
지도 데이터가 아직 수집되지 않았으며 마장동 지도는 운영에 반영하지 않았다.
필요한 호스트는 `www.openstreetmap.org`, `overpass-api.de`다.
생성 지도 3개 파일이 모두 있을 때만 개인화 변환이 새 지도를 활성화한다.

네트워크 설정이 적용되면 기록한 경계의 OpenStreetMap JSON을 확보한 후:

```sh
python tools/build-majang-map.py /tmp/majang.osm.json
npm run build
```

`tools/build-majang-map.py`는 실제 노드로 연결된 공개 보행 도로에서 주소에
가까운 닫힌 골목 순환 경로를 찾는다. 차량 전용 도로·사유지·보행 금지 구간을
제외하고, 도로를 가로지르는 임의 직선이나 동일 구간의 불필요한 왕복을 만들지
않는다. 적합한 루프를 찾지 못하면 오류로 멈춘다. 모서리는 교차점의 중심에서
1.5m 이내로 완만하게 이어 붙인다. 결과에는 출처 노드와 원본 데이터 해시가
남는다. 지도 데이터는 ODbL을 따르며 기존 OpenStreetMap 출처 표기를 유지한다.

생성 결과는 `public/personal/map/`의 밝은/어두운 SVG와 `route.json`이다.
기존 사진 핀·하단 카드·테마·화면 밖 일시정지·45초 루프는 그대로 사용한다.
지도 확대·드래그·GPS 추적은 이 변경 범위에 포함하지 않는다.

실제 현장 보행 가능성이나 최신 공사·통행 제한은 OSM만으로 보장할 수 없다.
산책을 표현하는 애니메이션이며 실시간 위치 또는 길 안내가 아니다.
