# 대화 작업실

- 작성: `https://gwangil.xyz/chat/studio/`
- 방문자: `https://gwangil.xyz/chat/`
- 로그인: 기존 `/inbox/` 메시지함 비밀번호와 같은 로그인 세션. 공개 메뉴에는 작업실 링크를 넣지 않는다.

## 작성 순서

1. 500개 질문 중 검색하거나 주제/답변 상태로 골라 연다.
2. 답변을 입력하고 화살표 또는 Ctrl/⌘ + Enter로 말풍선을 추가한다. Enter는 줄바꿈이다.
3. 사진과 링크도 말풍선으로 추가할 수 있다. 사진은 JPG/PNG/WebP를 선택하거나 붙여넣는다. 브라우저에서 최대 1800px JPEG로 변환해 업로드한다. 서버 한도는 3MB다.
4. 각 말풍선에서 수정·삭제·위/아래 이동이 가능하다.
5. `임시저장` 또는 `답변 완료`는 서버에 비공개로 저장한다. `나중에`도 현재 내용을 저장하고 다음 미작성 질문으로 이동한다.
6. `미리보기`는 방문자가 보게 될 질문/답변 방향과 말풍선 순서를 재생한다.
7. `답변 완료` 뒤 `Chat에 공개`를 누르면 해당 저장본을 방문자 Chat에서 바로 읽는다. 재배포는 필요 없다.
8. 공개 후 답변을 수정해도 기존 공개본은 유지된다. 수정본도 다시 `답변 완료` → `Chat에 공개`해야 반영된다. `공개 내리기`는 답변을 보관하고 방문자 화면에서 숨긴다.

초안은 입력할 때 브라우저에 보관한다. 기기를 옮기기 전에는 서버 저장 버튼을 눌러야 한다. 다른 창/기기와 저장 버전이 충돌하면 덮어쓰지 않고 안내한다. 현재 초안을 내려받거나 서버 저장본을 불러올 수 있다.

## 데이터

- `hosting/generated/chat-bank.json`: 질문 후보 500개. 기존 공개 예시 18개와 새 질문 482개. 작업실에서 기존 답변은 예시로 표시한다.
- Vercel private Blob의 기존 `itsme/store.json`에 `chatStudio.records`와 `chatStudio.media`를 추가한다. 메시지함·구독·평점 데이터는 유지한다.
- 사진 원본 경로는 private Blob `itsme/chat-media/`. 공개 답변에서 참조하는 사진만 비로그인 요청에 제공한다.
- `GET /api/chat-studio/`: 인증된 작성자가 질문과 저장본 조회.
- `POST /api/chat-studio/`: save/publish/unpublish. 질문별 revision과 요청 UUID로 충돌 및 중복 재시도를 처리한다.
- `POST /api/chat-media/`: 인증된 사진 업로드. `GET`은 로그인 세션 또는 공개 답변의 참조를 확인한다.
- `GET /api/chat-content/`: 공개된 답변만 제공. 입력된 문장·줄바꿈·말풍선·미디어 순서를 보존한다.
- `답변 내려받기`: 질문/저장본 JSON 다운로드. 사진은 파일 자체 대신 접근 주소가 포함된다.
- 로컬 저장은 `.data/store.json`, 사진은 `.data/chat-media/`이며 Git에 포함하지 않는다.

새 질문을 추가하려면 질문은행에 고유 ID를 부여해 추가한다. 답변 내용은 작업실 저장본이 우선한다. 이 경로는 런타임 API가 필요하므로 순수 정적 호스팅만으로는 동작하지 않는다.

## 검증

`node --test tests/chat-studio.test.mjs`는 인증/출처 제한, 글·사진·링크의 영속 저장, 재시도, 동시 수정, 업로드 검증, 공개 스냅샷, 공개 해제 후 사진 접근 차단, 로컬 서버 재시작 후 복원을 검증한다. 전체 회귀 검사는 `npm test`, 빌드/보존 검사는 `npm run build`와 `npm run audit`를 실행한다.
