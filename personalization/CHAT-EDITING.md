# Chat 콘텐츠 편집

기존 Messages 화면을 사용하는 `/chat/`입니다. `/newsletter/`도 같은 대화 화면을 표시합니다. 자유 입력은 전송되지 않고 질문 목록을 검색합니다. 답변은 준비된 순서대로 표시되며, 외부 AI/API를 호출하지 않습니다.

## 엑셀로 편집

1. **질문 목록**에서 고유 ID, 주제, 질문, 쉼표로 구분한 검색 키워드와 후속 질문 ID를 입력합니다. `첫 질문=예`는 초기 추천, `공개=아니오`는 비공개 초안입니다. 작성 메모는 화면에 노출되지 않습니다.
2. **답변 순서**에서 같은 질문 ID를 여러 행에 반복하고 순서를 1, 2, 3으로 넣습니다. `text`는 말풍선, `photo`는 사진, `link`는 링크입니다. 사진 설명과 링크 제목도 채웁니다.
3. 새 사진은 `public/personal/chat/` 폴더에 넣고 엑셀에는 `/personal/chat/파일명.jpg`로 적습니다. 엑셀에 이미지를 직접 붙이지 않습니다. 기존 `/personal/` 파일도 사용할 수 있습니다. 사진은 클릭해서 원본 크기로 볼 수 있습니다.
4. 표의 열 이름·시트 이름은 유지하고 아래에 행을 추가합니다. 한 셀의 줄바꿈은 유지됩니다. 수식은 지원하지 않습니다.
5. 저장 후 저장소에서 실행합니다:

```powershell
npm run chat:import -- "C:\전체경로\광일_Chat_질문답변.xlsx"
npm run dev
```

Python 3과 Node.js가 필요합니다. 가져오기는 ID, 답변 순서, 후속 질문, 로컬 사진 파일, URL을 검사한 후에만 반영합니다. 잘못된 파일은 기존 콘텐츠를 덮어쓰지 않습니다. 비공개 질문과 작성 메모는 공개 JSON에서 제외됩니다. 수정한 파일을 Codex에 전달해 반영해도 됩니다.

## 로컬 예시

18개 질문은 기존 사이트의 소개와 프로젝트 정보를 대화로 다듬은 예시입니다. 일부 연결 문구는 시연용이므로 공개 전에 본인 말투로 검토해주세요. 개인 사진은 기존 사이트 자산이며 갈팡질팡 이미지는 프로젝트 연출 이미지, LOAM 화면은 데모 화면입니다.

원본은 `personalization/chat-content.json`, 브라우저용 데이터는 `public/personal/chat-data.json`입니다. 로컬 실행과 배포 빌드는 검증된 공개 데이터만 다시 생성합니다. 대화 기록은 현재 탭에서만 유지되고 새로고침 또는 ‘처음부터’로 초기화됩니다. ‘직접 메시지 남기기’는 Chat 화면 안에서 작성창을 열고, 보낸 메시지는 기존 비공개 받은 편지함(`/inbox/`)에 저장됩니다. 작성창을 닫았다 열어도 전송 전 내용은 유지되며, 페이지를 새로고침하면 지워집니다.
