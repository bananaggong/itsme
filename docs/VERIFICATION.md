# 검증 기록 — 2026-10-16

## 환경 및 재현

- 원본: `https://www.samdickie.me/`, 클론: `http://localhost:3000`.
- 도구: Playwright + 환경의 Linux Chromium. 연결된 Browser 제어 도구가 이 채팅에 노출되지 않아 이 경로를 사용했습니다.
- 기준: PC 1440×1000, 모바일 390×844, device scale 1, locale en-GB, 시간대 Asia/Seoul.
- 정적 비교는 reduced motion, 폰트·보이는 이미지 로딩 완료, 아카이브 링크 강조 종료 후 촬영. Newsletter 대화는 맨 아래로 정렬.
- 기능 검사는 원본과 클론에서 같은 사용자 입력을 수행. 원본 API의 POST는 차단해 실제 원본 데이터는 변경하지 않았습니다.
- 평점/이메일 저장 검사는 임시 클론 서버와 임시 데이터 디렉터리에서 실행하고 이후 제거했습니다.

```sh
npm start
# 다른 터미널에서:
npm run test:e2e
npm run test:interactions
npm run test:edges
```

## 화면 대조 및 수정 기록

원본 PNG와 최신 클론 PNG를 `view_image`로 직접 열어 PC 전체 홈·모바일 홈·뉴스레터·아카이브·다크 화면을 대조했습니다. 비교 기준은 원본 실화면이며 이미지 생성으로 대체하지 않았습니다.

| 색/면 | 흰 배경과 light/dark 타일·글자·테두리·지도 변형·그라데이션 원본 CSS 보존 |
